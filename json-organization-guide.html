📊 Düzenli ve Kategorik JSON Yazma Rehberi

1. Temel Prensipler

✓ Hiyerarşik Düzen: Verilerinizi mantıksal seviyeler halinde organize edin
✓ Kategori Gruplandırması: İlişkili verileri alt nesnelerde toplayın
✓ Tutarlı Yapı: Aynı türdeki veriler aynı şekilde gösterilsin
✓ Net Adlandırma: Açık ve özlü anahtar isimleri kullanın

5. Adlandırma Kuralları

Kural Doğru ✓ Yanlış ✗
camelCase kullanın firstName first_name, FirstName
Çoğul liste adları users, posts user, post
Boolean öneki isActive, hasPermission active, permission
Açık ve anlaşılır createdAt, description c, desc, d

7. Kontrol Listesi

  • ✓ Verileri mantıksal kategorilere bölün
  • ✓ İlişkili verileri iç nesnelerde toplayın
  • ✓ Metadata ve içeriği ayırın
  • ✓ Durum ve veri tipine göre gruplandırın
  • ✓ Tutarlı camelCase adlandırma kullanın
  • ✓ İç içe sayısını 3-4 seviyeyle sınırlandırın
  • ✓ Boolean alanlar için is veya has öneki kullanın
  • ✓ Açık ve özlü anahtar isimleri seçin
  • ✓ Çoklu öğeler için çoğul isimler kullanın
  • ✓ Tarihler için ISO 8601 formatını kullanın
